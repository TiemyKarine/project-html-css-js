Projeto HTML, CSS e Javascript

Projettodesenvolvidos com HTML, CSS Javascript puro, criados para praticas logicas de programação, estilização, responsividade e manipulação do DOM.

Tecnologias Utilizadas 🛠️
* HTML5 - estruturas sematicas;
* CSS3 - estilização, flex/grid, animações e responsividades;
* Javascript - logica, manipulação do DOM;

 
 Objetivo do repositório 🧠

Este repositório reúne exercícios práticos para consolidar conceitos de front-end como:

*Manipulação do DOM
*Eventos e interatividade em JavaScript
*Layout responsivo com Flexbox/Grid
*Validação de formulários
*Boas práticas de organização de código
